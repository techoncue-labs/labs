# Contributing

Thanks for helping keep these guides useful.

- **Found an outdated step?** Tools change fast. Please open an issue with the guide name, the step, what you expected, what happened, and the tool version you used.
- **Small fixes** (typos, broken links) are welcome as pull requests.
- Keep changes to our own files: guides, compose files, and sample-data scripts. Don't add copies of upstream code, images, or logos; link to the official source instead.
- Never commit real passwords, API keys, tokens, or personal data. Use placeholders like `CHANGE_ME_long_random_string`.
